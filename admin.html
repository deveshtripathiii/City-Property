WhatsApp Enquiry System

City Property uses a WhatsApp-based enquiry system. When a user clicks "Enquire Now" or "WhatsApp" on any listing, they are directly connected to +91-97117 33120 with a pre-filled message containing the property title, location, and price. This ensures fast response times and no leads are lost in a database.

How Enquiries Work

📱
Step 1 – User Clicks Enquire
User browses the listing and clicks "Enquire on WhatsApp" button on the property page.
💬
Step 2 – Pre-filled Message
WhatsApp opens with a pre-filled message: property name, location, price, and user's interest.
⚡
Step 3 – Instant Connection
The message goes directly to +91-97117 33120. Our team responds within minutes.
✅
Step 4 – Lead Converted
Site visit is scheduled, deal is closed. 100% transparency, no middlemen.
📌 Note on CID (Conversation ID):

The CID in the website URL (e.g., ?cid=d1c9...) is a unique conversation tracking ID automatically assigned per browser session. This helps in future implementations to correlate enquiries with browsing sessions for better lead attribution and follow-up automation.
